# Paperfoot

**Better health. Longer lives. Less suffering.** For dogs, humans, and beyond.

Paperfoot builds AI for ageing and biology — not language models repackaged for health, but tools built to understand biology directly. Genomics, proteomics, clinical signals, and the command-line tools that glue it all together.

This org hosts our open-source CLIs. Small, composable, JSON-on-stdout. Each tool does one job and composes with the rest.
